# Security policy

This SDK is an experimental developer preview. It has no production support commitment yet.

To report a vulnerability, email **anton@gateivo.com** with the affected version, impact and a minimal reproduction using fictional data. Please avoid posting an exploit involving a real deployment in a public issue before we have had an opportunity to investigate.

Do not send access tokens, refresh tokens, API keys or customer records. We can agree on a suitable way to exchange additional evidence if needed.

We currently maintain only the latest preview. There is no guaranteed response or remediation timetable during this stage.

For configuration requirements and trust boundaries, see [the authentication guide](docs/authentication.md).
